# The Olive Rooms

A premium, responsive resort website designed for **The Olive Rooms / Olive Downtown**, with a dark luxury visual identity, interactive animations, responsive layouts, reservation enquiry functionality, location integration, and a dynamic light/dark theme.

## ✨ Project Overview

The Olive Rooms is a modern luxury resort website built with HTML, CSS, and JavaScript.

The project focuses on creating an elegant hospitality experience through:

- Luxury dark-themed UI
- Responsive design
- Smooth animations and transitions
- Interactive navigation
- Light and dark mode
- Resort gallery and experience sections
- Reservation enquiry page
- Google Maps location integration
- Contact section
- Journal / blog section
- Scroll-to-top interaction
- Auto-hiding navbar
- Mobile-friendly layouts

## 🚀 Features

### 🌓 Dark & Light Mode

The website includes a complete theme switcher.

**Dark Mode**
- Black and deep olive backgrounds
- Gold accents
- Premium luxury appearance
- Cinematic visual styling

**Light Mode**
- Warm ivory / cream background
- Olive green accents
- Champagne/gold details
- Maintains the same animations and interactions as dark mode

The selected theme is stored locally so it remains available across pages.

### 🧭 Smart Navbar

The navigation bar includes:

- Home
- Services
- Journal
- Contact
- Reservations
- Reserve button
- Dark/Light mode control
- Mobile menu

The navbar is visible when the visitor is at the top of the page.

Once the user scrolls down, the navbar smoothly slides upward and hides.

When the user returns to the top of the page, the navbar slides down and becomes visible again.

### ⬆️ Scroll-to-Top Button

A floating scroll-to-top button appears after the visitor scrolls down the page.

Clicking it smoothly returns the visitor to the top.

### 📱 Fully Responsive

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile phones

Layouts, navigation, buttons, images, cards, forms, and typography automatically adapt to different screen sizes.

### 🎞️ Animations

The website uses smooth visual effects including:

- Hero animations
- Image transitions
- Floating elements
- Reveal-on-scroll effects
- Hover interactions
- Smooth theme transitions
- Navbar slide animations
- Button transitions
- Background effects

### 🖼️ Resort Imagery

The website uses dedicated images throughout the project, including:

- Morning / sunrise imagery
- Bar
- Golden hour
- Fireplace
- Poolside
- Fine dining
- Resort / contact building imagery
- Resort logo

Each image is placed according to the corresponding section of the website.

### 📍 Google Maps Integration

The Contact page includes an interactive Google Maps location for:

**Olive Downtown**  
28/286, Jn, Kadavanthra Junction,  
Kadavanthra, Kochi, Ernakulam,  
Kerala 682020, India

The map is visually integrated with the website's luxury theme.

### 📝 Reservation Page

The reservation section allows visitors to submit booking enquiries and provide their details.

The project is structured so the reservation system can be connected to external services such as:

- Google Sheets
- Google Apps Script
- Google Drive
- Email notification systems
